# Telegram бот для напоминаний об оплате серверов

## Возможности
- Напоминания за 2 дня, за 1 день и в день оплаты (в 08:00 и 17:00 по МСК).
- Кнопка `Я оплатил` в уведомлении с вводом новой даты в формате `xx xx xxxx`.
- Учёт расходов по каждому серверу и суммарно (`/total`).
- Список серверов (`/all`) с кнопками и детальной карточкой.
- Список провайдеров (`/providers`) с переходом к их серверам.
- Удаление серверов и провайдеров через команды `/delete_server` и `/delete_provider`.
- Карточка сервера: провайдер, IP, `user/passwd`, `acc user/acc passwd`, ссылка на провайдера.
- Добавление провайдера (`/add_provider`) и серверов (`/add_new_server`) прямо в боте.
- Баланс и последние 3 расхода (`/balance`) + ручная корректировка в формате `+100` / `-100`.
- `start`-экран с доступом к панели и быстрыми кнопками.
- Ограничение доступа в личке только для разрешенных Telegram user id.
- В групповых чатах бот обрабатывает только `/ping` и `/help`.

## Команды
- `/start` — главное меню
- `/help` — список команд
- `/add_provider` — добавить провайдера
- `/add_new_server` — добавить сервер
- `/providers` — список провайдеров
- `/delete_provider` — удалить провайдера
- `/delete_server` — удалить сервер
- `/all` — список всех серверов
- `/upcoming` — предстоящие оплаты на неделе
- `/total` — сумма расходов по каждому серверу и общая
- `/balance` — текущий баланс + 3 последних расхода
- `/server-info-<name>` — карточка сервера по имени
- `/ping` — проверка доступности всех серверов через `ping -c 4`
- `/ping_название_сервера` — пинг конкретного сервера (в т.ч. с emoji/флагами в названии)

## Доступ
- Список разрешенных user id задается через `.env`: `ALLOWED_USER_IDS` (через запятую).
- Уведомления о командах от пользователей вне whitelist отправляются в `ALERT_CHAT_IDS`.
- Для всех остальных пользователей в личке бот отвечает отказом в доступе.
- В группах бот поддерживает только `/ping` и `/help`.

## Запуск
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# заполните BOT_TOKEN и опционально параметры панели
export $(cat .env | xargs)
python bot.py
```

## Примечания
- Для отправки фоновых напоминаний бот должен быть запущен постоянно.
- Напоминания отправляются в последний чат, где вы вызвали `/start`.
